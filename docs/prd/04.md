## 4. 核心原则（产品层）

1. **忠于用户打开的那份 PDF。** 任何模型输出都是「候选」，经过校验与质量评分才能算已核验；校验不过显示原页裁图。没有 Jev 有效高分的识别结果都不算已核验：程序核对通过的公式显示 LaTeX 但标「格式已核对」，arXiv 源码核对通过的标「源码核对」（§3.4、§3.5）。「源码核对」算不算已核验仍待定。
2. **不静默丢内容。** 公式、数字、引用编号、正文段落少了要报错或标待复核，不能悄悄消失。
3. **花钱可见、可控。** 每次付费调用可追溯到任务；所有付费调用（包括默认就会出网的 Jev 与引擎 B）发出前先预留额度，单价未知时按请求数、页数或 token 上限控制；受限预算到上限立即停；超时不盲重发。
4. **重开即所得。** 已解析、已翻译、已采用的结果重开后原样恢复，不再发请求。
5. **没有服务也能读。** 没装 Python、没配服务时，仍能打开 PDF、读文字层、看裁图、记笔记。

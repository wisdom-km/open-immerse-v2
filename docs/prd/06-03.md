### 6.3 视觉与交互验收对照

Loom 的 [DESIGN.md](../../DESIGN.md) DS-01–DS-31 与 §6.1、§6.2 验收的对照。有 AC 的，断言以 AC 的原文为准；没有 AC 的是界面或无障碍验收，不另设产品门槛。冲突与裁决写在 DESIGN.md 文首的入库说明。

| DS | 对应验收 | 关系 |
| --- | --- | --- |
| DS-01 | 无 AC | 颜色对比度。原则见 [docs/design-principles.md](../../docs/design-principles.md) §4。 |
| DS-02 | 无 AC | 阅读区与外壳 token 不混用。 |
| DS-03 | 无 AC | 跟随系统浅色 / 深色；不提供应用内颜色模式开关（Wisdom 2026-11-04 03:08）。 |
| DS-04 | 无 AC | 强制色下文字、边框、焦点可见。 |
| DS-05 | 无 AC | 主路径键盘可达。重试按钮的焦点见 AC-56。 |
| DS-06 | AC-56 | 焦点环可见。AC-56 只锁译文块的 `--oi-reader-focus`；全局 `:focus-visible` 以 DS-06 为准。 |
| DS-07 | 无 AC | 减少动效。 |
| DS-08 | AC-56 | 状态用 `role=status`。AC-56 锁重译失败的提示行；其余图标按钮的 `aria-label` 以 DS-08 为准。 |

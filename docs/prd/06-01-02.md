#### 6.1.2 译文区块（D6 补充，AC-57–AC-58）

来自 Loom 2026-10-30 对译文区块风险的结论（翻译块范围、缓存键），论证见[差异清单](../../docs/v2-gap-and-changes.md) §6.2。

| 编号 | 标准 | 对应 |
| --- | --- | --- |
| AC-57 | 译文缓存键与公式决定摘要（core 测试，夹具采用版本）：① 重新采用、块的占位文本与 `formulaDigest` 都不变 → 翻译请求 0 次，新记录的 `markdown` 与旧记录逐字节一致；② 改一个公式的已核验 LaTeX → 只有含它的块重新请求；③ 同一公式的显示决定在 `verified-latex` 与 `source-crop` 之间切换、LaTeX 字节不变 → 摘要改变，旧正文被复用 0 次；④ 换候选来源但采用的 LaTeX 字节相同 → 请求 0 次；⑤ 文字不变而块类型改变 → 重新请求；⑥ 请求发出后采用了新版本 → 回来的结果写到新版本记录上 0 次；⑦ 记录上的摘要与当前不一致 → `getBlocks` 不返回旧正文并自动排队重译；⑧ 提示词构造读到的每一项输入都在缓存键里（契约测试）；⑨ 同一公式的显示决定在 `verified-latex`、`source-checked-latex`、`format-checked-latex` 之间切换（含翻转 ARCHITECTURE §7.5 的决定点）、LaTeX 字节不变 → 摘要不变、翻译请求 0 次，`getBlocks` 给出的公式标记随当前决定改变；在 `source-crop` 与 `page-placeholder` 之间切换 → 摘要改变，旧正文被复用 0 次 | US-04, US-08；M4 |
| AC-58 | 翻译块范围：正文段落、标题、图表题注、脚注、列表项、引用块生成翻译块；表格、图、独立公式生成 0 个翻译块（表格和图显示原文裁图，只有题注进翻译；独立公式走公式回退链）；对非翻译块调用 `retranslateBlock` 返回 `block_not_translatable`；列表项、引用块、标题的 `markdown` 不含列表、引用、标题标记，模型文字行首的这类标记被转义，渲染出的块类型只由文档模型决定（core 测试） | US-02, US-28；M4 |

# 0012 只画视口附近的页，并加上单页画布像素上限

状态：提议。日期：2026-11-14（Asia/Shanghai）。决定人：待 Wisdom 在本页从「提议」改为「采纳」时再写。本页现在只记录 2026-11-14 14:17 已批的方案 A，实现仍等批次 E 的计划审查通过。

批准时间：2026-11-14 14:17（Asia/Shanghai）。原话：「按推荐 A：批次 E 加入只画视口附近 ±2 页（#202 开工）和单页画布像素上限，只改阅读器 UI，写新 ADR 修订 0011；8GB 真机超限仍停；不 Ready/合入/发版」。来源：[Issue #174 评论 6872986479](https://github.com/wisdom-km/open-immerse-v2/issues/174#issuecomment-6872986479)，同一原话也在 [Issue #202 评论 6872987059](https://github.com/wisdom-km/open-immerse-v2/issues/202#issuecomment-6872987059)。

本页只修订 [0011](0011-tab-working-set.md) 里「不改成只画视口附近的页 / 视口绘制暂不开工」这一条。0011 的其余条款不动：不实现画布清零，不调用 `PDFDocumentProxy.cleanup()`，不改 CSP、协议注册、主进程、core、contracts、`library/src`。0011 仍是已采纳。本页在被采纳之前不取代 0011。

## 背景

0011 在测量脚本里比较过「25 页都画」和「只留当前页 ±2」。压力之后的 `[anon]` private dirty，二十轮是 115600 KB 对 173912 KB。只留附近页的一边更高。只留附近页一侧的 Tab working set 在二十轮压力后是 287440 KB，当前路径是 231584 KB。降下来的是压力本来就会清掉的 memfd 共享内存。静置和压力都留着的匿名页没有下降。这是 0011 的实测局限，本页不把它写成已经解决。

批次 E 要在 400% 下画 PDF。0011 记过 25 页在 scale 1 时 canvas 像素 48,470,400 字节。400% 时面积约是 16 倍，这是按 4×4 算的推算，不是实测。Wisdom 2026-11-14 14:17 因此把 #202 并进批次 E，并加上单页像素上限。8 GB Windows 真机超限仍停。超限的 MB 数待 Wisdom，本页不写。

## 选项

1. 维持 0011：视口绘制不开工。代价：400% 仍按页数把每一页都画上。
2. 离开时把 canvas 宽高设为 0，或调用 `PDFDocumentProxy.cleanup()`。0011 的四轮对照里，匿名私有脏页没有降下来。不采用。
3. 分块渲染，或改主进程、协议、CSP 去清分配器保留。碰到本批禁区。不采用。
4. 只改阅读器 UI：第一张可见页减 2 到最后一张可见页加 2 保留 canvas，夹到 1..总页数。其余页释放 canvas，按各页实际尺寸乘缩放留出占位高度。单页画布像素超过上限时，渲染 scale 取上限对应的 scale，显示尺寸用 CSS 拉伸。

## 决定

选第 4 条，作为提议。Wisdom 2026-11-14 14:17 已点选方案 A。实现范围写在 `docs/exec-plans/feature-reader-nav-zoom-174.md`。本页还不是「采纳」：计划审查通过、实现合入之前，0011 那一条「暂不开工」仍然是已采纳的原文。

- 主改 `packages/features/reader/src/ui/page-column.tsx`。卸下的页走这个文件里已有的 cancel。
- 占位按每一页自己的 PDF 尺寸乘缩放。不用统一的估算高度。横版页各算各的。
- 占位不放转圈，不写「加载中」。挂上或卸下 canvas 时不改文档总高度，不改滚动位置，不因此调用页码写回。释放和重画不进入读屏、焦点和 Tab 顺序。
- 像素上限写在 `packages/features/reader/src/ui/pdf-session.ts`。上限是可调常量，数值等实测，不在本页写死。超过上限只用 CSS 拉伸，不提示。
- 不加内存开关、提示或降级横幅。不做分块渲染。不调用 `PDFDocumentProxy.cleanup()`。
- 8 GB 真机超限就停，不放宽上限来过这一关。超限的 MB 数待 Wisdom。
- 释放 canvas 时要不要先把宽高设为 0，待 Wisdom。本页不把第 7 行附近「不实现画布清零」收窄成其中一边。那一句仍是 0011 的条款，说的是离开阅读屏。
- 不含 Ready、合入、发版。

## 后果

- 同时存在的 canvas 不超过可见页数加 4。400% 时可见页通常是 1 到 2 页，所以上界不会比「最多 5 张」更大。滚动和跳页会换这一组。占位高度用来稳住滚动和「第 N / M 页」。
- 0011 已经量到：这样做不保证压力后的 `[anon]` 下降。进出阅读屏留下的匿名页仍按 0011 的结论保留。
- 单页像素上限只降低单张画布的后备存储。CSS 拉伸可能在超过上限时变糊。这是用清晰度换内存，数值由实测选定。

## 12. 测试策略

| 层 | 工具 | 要求 |
| --- | --- | --- |
| core（domain + application，经 seam） | Vitest 工程 `core`（`environment: 'node'`）/ pytest | 测试文件放 `test/core/`，只 import `src/index.ts`、`src/pure.ts`、`src/testing/**`；不渲染 UI、不启动 Electron、不联网、不加载模型；每条从 v1 移植的规则带原 v1 用例。这是 Q3 的完成标准（G16） |
| core 属性与病态输入 | fast-check（MIT）；子线程 + 超时 | `markdown` 的往返不变 `serialize(parse(t)) === t`（AC-52）与 `translation` 的「还原后公式与片段表一致」（AC-49）用随机生成文本跑；Markdown 解析对病态输入（深层嵌套、超长行、大量 `$`）在子线程运行并设超时，超时即失败（沿用 v1 `tests/helpers/render-guard.mjs` 的做法） |
| adapters | 契约测试套件 | 每个端口在 `testing/` 提供一份共享契约测试，内存实现与 SQLite 实现都跑同一份 |
| 协议 | TS + Python 双侧 | `fixtures/protocol/` 合法样例通过、非法样例拒绝；含 `provider-errors/`（`ProviderFailure` 映射）与 `versions/`（协议版本协商，§10.4） |
| 解析规则对拍 | `fixtures/parsing-rules/`，TS + Python 双侧 | 阅读顺序、扫描页判定、段落切分的每个夹具两侧输出逐字段一致（§7.10）；夹具只用合成几何、合成文字与页面特征 |
| 服务商适配层 | `packages/providers/src/testing/`（计划中）的共享套件 | 每个格式适配器跑它支持的能力对应的套件（chat、vision、streaming、ocr、errors、auth、budget-egress）；每条注册表记录至少跑 auth 与 errors；样例在 `fixtures/providers/<vendor>/`，全部是合成数据（§7.9.7） |
| ui | Vitest + Testing Library | 组件只依赖 fake 的 `window.oi`；只断言「调用了哪个 seam、怎么画结果」，不断言业务规则（规则已由 core 测试覆盖） |
| e2e | Playwright Electron | 只做少量冒烟：开窗、导入、阅读、重开 |
| 基准 | 独立脚本 | 不作为 CI 门禁；结果写入 `docs/acceptance/` |

- **夹具只用合成数据**（架构评审 P2-8）：`fixtures/protocol/`、`fixtures/providers/`、`fixtures/parsing-rules/` 与录制样例只用合成图、合成文字与假令牌，不放真实论文页面的图片、裁图或正文。需要真实页面的基准走不入库的语料流程，仓库只存清单与 sha256（`fixtures/corpus/`）。
- 测试只断言行为，不读取源码文本（F-08）。
- CI 不调用付费 API、不下载模型权重；需要真实模型的测试标记为 `@model`，只在手动或夜间任务运行。
- 每个模型能力的「本地」与「API」两个来源跑同一份契约测试（假后端或去掉凭据与图片内容的录制样例）。M0/M1 里「本地」来源跑的是 stub，不跑真实本机推理；接口与契约仍和 API 来源同一份（§7.0，Wisdom 2026-11-02）。调用真实托管 API 的冒烟测试标记 `@live`（按 RULES §4 的 `@paid` 对待，有调用次数上限），只在对应 Key 已由 Cursor Secrets 注入时运行，否则跳过；不是 CI 门禁。
- 运行纪律（每个提交 tip 全量只跑一次、失败只重跑失败项）见 RULES.md §4。
- **core 测试不依赖界面（Wisdom 2026-10-30 23:56）。** core 测试在没有安装或编译界面包的情况下能跑完：不启动 Electron，不加载 renderer，不 import `src/ui/**`。只改界面（`src/ui/**`、`apps/desktop/src/renderer/**`、`ui-kit`）时，core 测试的期望与结果都不变（PRD AC-100）。M1 前此项写不适用（脚本尚未提供）；M1 起以 package.json 实际脚本为准。不新增空脚本顶替。

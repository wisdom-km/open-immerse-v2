## 3. 目录结构

pnpm workspace + Python `uv` 项目。下面每个目录都是**可以独立测试、独立认领**的单位。

```text
open-immerse-v2/
├─ PRD.md  ARCHITECTURE.md  RULES.md
├─ DESIGN.md                          # Loom 2026-10-30 入库；正文不改
├─ docs/
│  ├─ design-principles.md            # Loom 2026-10-30 入库；正文不改
│  ├─ design/                         # Loom 的功能级设计文档（md-reader.md、wireframe-vault.svg）
│  ├─ v1-review.md  v2-gap-and-changes.md
│  ├─ adr/                            # 架构决策记录：NNNN-标题.md
│  ├─ acceptance/                     # AC / QM 到测试用例的映射
│  └─ architecture/                   # 早期草案（历史输入，非权威）
├─ apps/
│  └─ desktop/
│     ├─ src/main/                    # 装配根、IPC 路由、窗口、安全、worker 监管
│     ├─ src/preload/                 # 由契约生成的 window.oi
│     ├─ src/renderer/                # 当前只有 index.html；路由、布局插槽、全局 Provider 为计划中
│     └─ e2e/                         # Playwright Electron 冒烟测试
├─ packages/
│  ├─ contracts/                      # 公共类型包（唯一跨进程 / 跨语言类型来源）
│  ├─ kernel/                         # 最小运行时无关原语：Result、AppError、Logger 接口、Clock、Id
│  ├─ platform-node/                  # Node 侧基础设施：SQLite、文件资产、safeStorage、HTTP 客户端、日志落盘
│  ├─ worker-client/                  # 计划中。oi-parse/1 的 TS 客户端（本机 / 远程共用）
│  ├─ providers/                      # 服务商适配层：注册表、按 API 格式的适配器、鉴权方式、契约测试套件（§7.9）
│  ├─ ui-kit/                         # 计划中。设计令牌与基础组件（按 Loom 的 DESIGN.md 实现）；markdown/ 为共享 MarkdownView（§4.5.4）
│  └─ features/                       # 按功能切片，见 §4
│     ├─ budget/  formula-source/  ingest/  jobs/  markdown/  # 已建
│     ├─ library/  document/  parsing/  formula/  translation/  # 计划中
│     ├─ quality/  repair/            # 计划中。ADR 0003 删的是 repair → quality，不是这两个切片（§4.2）
│     ├─ reader/  notes/  qa/  voice/ # 计划中
│     └─ settings/  diagnostics/      # 计划中。writing/ 为预留位，v2 不建目录（§4.4）
├─ workers/
│  └─ parser/                         # Python worker（uv 项目），见 §10.3
├─ fixtures/
│  ├─ protocol/                       # TS 与 Python 共用的协议样例（合法 / 非法；含 provider-errors/、versions/）
│  ├─ providers/                      # 计划中。各服务商的契约测试样例（合成数据，不含真实 Key 与论文页面，§7.9.7）
│  ├─ parsing-rules/                  # 计划中。解析规则集的两侧对拍夹具：reading-order/、scan-detect/、paragraphs/（合成几何与文字，§7.10）
│  └─ corpus/                         # 计划中。基准论文清单（只存清单与 sha256，不存 PDF）
└─ tools/
   ├─ check-commits/
   ├─ check-core-tests/
   ├─ check-deps/
   ├─ check-docs/
   ├─ check-file-size/                # 行数门禁
   ├─ check-format/
   ├─ check-hotspots/                 # 热点文件登记校验
   ├─ check-license/
   ├─ check-one-slice/
   ├─ check-pr-size/
   ├─ check-secrets/
   ├─ codegen/                        # run.mjs 生成 workers/parser/oi_worker/protocol/，datamodel-code-generator 钉 0.87.0（tools/codegen/pin.json）
   ├─ compare-spec-bytes/
   ├─ eslint/
   ├─ gate-fixtures/
   ├─ gate-remediation/
   ├─ spawn-bin/
   ├─ tsconfig-core/
   ├─ typecheck.mjs
   └─ vitest-collect/
```
